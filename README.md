
# Mnajem (مناجم) - منصة تواصل اجتماعي وخدمات متكاملة

مناجم هو تطبيق محمول متكامل وجاهز للإنتاج، تم بناؤه باستخدام إطار العمل Flutter. يعمل التطبيق كمنصة موحدة تجمع بين شبكة اجتماعية، سوق إلكتروني، منصة للوظائف، ومحفظة رقمية، مما يخلق نظامًا بيئيًا غنيًا للمستخدمين للتفاعل والتجارة والبحث عن الفرص.

## ✨ الميزات

-   **تسجيل الدخول والمصادقة**: نظام آمن لتسجيل حسابات جديدة وتسجيل الدخول للمستخدمين.
-   **صفحة الاستكشاف (Explore)**: مركز اجتماعي رئيسي حيث يمكن للمستخدمين مشاركة المنشورات (نصوص وصور)، واكتشاف المحتوى، والاطلاع على الهاشتاجات الرائجة، والتواصل مع الأصدقاء المقترحين.
-   **السوق الإلكتروني (Marketplace)**: وحدة تجارة إلكترونية تتيح للمستخدمين عرض المنتجات وتصفحها، مع ميزات مثل عرض المنتجات في شرائح متحركة، والفلترة حسب الفئة، وواجهة مخصصة لإضافة المنتجات.
-   **سوق العمل (Work)**: قسم مخصص لنشر الوظائف والبحث عنها، حيث يمكن للمستخدمين فلترة الوظائف حسب الولاية، ونوع الوظيفة، والتصنيف المهني.
-   **الفيديوهات القصيرة (Shorts)**: قسم لعرض مقاطع الفيديو القصيرة بملء الشاشة مع تمرير عمودي، شبيه بمنصات الفيديو الحديثة، مع خيارات تفاعل مثل الإعجاب والتعليقات والمشاهدات.
-   **المحفظة الرقمية**: نظام محفظة مدمج لعرض رصيد الحساب (داخلي/خارجي)، وسجل المعاملات، وإجراء التحويلات المالية.
-   **الملفات الشخصية للمستخدمين**: صفحات شخصية للمستخدمين تعرض عدد المتابعين، النبذة التعريفية، ومنشورات المستخدم الخاصة.
-   **مكتبة مكونات مخصصة**: مجموعة غنية من الواجهات الرسومية (Widgets) المخصصة والقابلة لإعادة الاستخدام (مكونات `Suh...`) لضمان واجهة مستخدم متسقة وعالية الجودة عبر التطبيق.

## 🛠️ التقنيات المستخدمة (Tech Stack)

-   **إطار العمل**: [Flutter](https://flutter.dev/)
-   **إدارة الحالة**: [GetX](https://pub.dev/packages/get) - لإدارة الحالة، حقن التبعيات (Dependency Injection)، وإدارة المسارات (Routing).
-   **مكتبات واجهة المستخدم**:
    -   `flutter_svg`: لعرض ملفات SVG عالية الجودة.
-   **النمط المعماري**: نمط شبيه بـ MVVM باستخدام GetX (Views, Controllers, Bindings).
-   **فحص الكود**: قواعد Dart القياسية لفحص جودة الكود (Linting).

## 🏛️ البنية المعمارية وهيكل الملفات

يتبع المشروع بنية معمارية نظيفة وقابلة للتطوير مبنية على نمط GetX، مما يضمن فصلًا واضحًا بين الاهتمامات (Separation of Concerns).

```
lib/
├── app/
│   ├── modules/
│   │   ├── auth/         # وحدة المصادقة
│   │   │   ├── bindings/
│   │   │   ├── controllers/
│   │   │   └── views/
│   │   ├── explore/      # وحدة الاستكشاف
│   │   ├── market/       # وحدة السوق
│   │   ├── profile/      # وحدة الملف الشخصي
│   │   ├── ... (بقية الوحدات)
│   │
│   ├── routes/
│   │   ├── app_pages.dart
│   │   └── app_routes.dart
│   │
│   ├── utils/
│   │   ├── components/  # مكونات واجهة مستخدم معقدة (مثل PostView)
│   │   ├── widgets/     # مكونات واجهة مستخدم أساسية (مثل SuhButton)
│   │   ├── theme/       # الألوان والأنماط ومسارات الأصول
│   │   └── fun/         # دوال مساعدة
│   │
│   └── exports.dart     # ملف مركزي لتصدير المكتبات والملفات الشائعة
│
└── main.dart            # نقطة انطلاق التطبيق
```

-   **`modules/`**: يحتوي على الميزات الأساسية للتطبيق. كل وحدة قائمة بذاتها وتحتوي على `views` (واجهات المستخدم)، `controllers` (منطق العمل)، و `bindings` (حقن التبعيات).
-   **`routes/`**: يدير جميع مسارات التطبيق والتنقل باستخدام GetX.
-   **`utils/`**: مكتبة مشتركة تحتوي على المكونات الشائعة، الواجهات الرسومية المخصصة، تعريفات السمات (Theme)، والدوال المساعدة لتعزيز إعادة استخدام الكود والحفاظ على الاتساق.
-   **`exports.dart`**: ملف واحد لتصدير الحزم والملفات شائعة الاستخدام، مما يبسط عمليات الاستيراد (import) عبر المشروع.

## 🚀 التثبيت والإعداد (Installation & Setup)

اتبع هذه الخطوات لتشغيل المشروع على جهازك المحلي.

**المتطلبات الأساسية:**
-   تثبيت Flutter SDK (إصدار 3.x أو أحدث).
-   بيئة تطوير متكاملة (IDE) مهيأة مثل Android Studio أو VS Code.
-   محاكي (Emulator) أو جهاز حقيقي.

1.  **استنساخ المستودع (Clone the repository):**
    ```sh
    git clone https://github.com/suhaib0edu/mnajem.git
    cd mnajem
    ```

2.  **تثبيت الاعتماديات (Install dependencies):**
    ```sh
    flutter pub get
    ```

3.  **تشغيل التطبيق (Run the application):**
    ```sh
    flutter run
    ```

## الاستخدام (Usage)

تم تكوين التطبيق ليبدأ بشاشة البداية (`start_view.dart`) ثم ينتقل إلى المحتوى الرئيسي. نقطة الدخول الرئيسية هي `lib/main.dart`، وتتم إدارة جميع عمليات التنقل بواسطة مسارات GetX المحددة في `lib/app/routes/`.

أثناء التطوير، يمكن استخدام ميزة التحديث السريع (Hot Reload) في فلاتر لإجراء تغييرات سريعة على واجهة المستخدم والمنطق.

## ✅ جودة الكود والممارسات المتبعة

-   **الكود النظيف**: تلتزم قاعدة الكود بمبادئ الكود النظيف، بما في ذلك الفصل الصارم بين واجهة المستخدم ومنطق العمل والبيانات.
-   **الهيكلة الوحداتية (Modularity)**: يتم تغليف الميزات في وحدات خاصة بها، مما يجعل قاعدة الكود أسهل في الصيانة والتوسع والتصحيح.
-   **إعادة الاستخدام**: يوفر مجلد `utils` المركزي مكتبة من الواجهات الرسومية والمكونات المخصصة، مما يقلل من تكرار الكود ويفرض نظام تصميم متسق.
-   **اصطلاحات التسمية**: يتم اتباع اصطلاحات التسمية القياسية في Dart للملفات والفئات والمتغيرات لتعزيز قابلية القراءة.
-   **الاختبارات (Testing)**: البنية المعمارية صديقة للاختبار، مما يسمح بالتكامل المستقبلي لاختبارات الوحدة (Unit Tests) والواجهات الرسومية (Widget Tests) باستخدام أطر عمل مثل `flutter_test`.
